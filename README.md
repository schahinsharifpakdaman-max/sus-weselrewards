# GoalScorer Rewards

Ich bin Schahin, Vereinsvorsitzender des Sus Wesel. Unsere Senioren sollen im nächsten Jahr anhand einer punkte prämie bezahlt werden. Darum Suchen wir dich auf den besten App designer auf der gesamten Welt vor allem wenn es um Geld und Fussball vereine geht. Anbei findest du den promt für die App sowie den Plan inwiefern die App verbessert werden soll in Form von Markdown dateien. Plane nun die erstellung dieser app und berücksichtige alle in den Markdown files beschrieben befehle.

This project was built with [Lovable](https://lovable.dev).
